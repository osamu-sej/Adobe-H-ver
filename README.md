# カクス — PDFモザイク・墨消しツール

PDFの「見せられない部分」（電話番号・金額・口座・マイナンバーなど）を、**クリックとドラッグだけで**隠して、**文字ごと完全に削除したPDF**として書き出すブラウザアプリです。
PDFの処理はすべてブラウザ内のPDFエンジン（MuPDF / WebAssembly）で行い、**ファイルは端末の外に送信しません**（例外は上級者向けの「高精度の文字認識（クラウド）」だけで、設定でAPIキーを入れた人が文書ごとに選んだときに限り、ページの画像を Google Cloud Vision に送ります）。

## 速く隠すための工夫

| 操作 | Adobe Acrobat での一般的な手順 | カクス |
| --- | --- | --- |
| 電話番号を1つ隠す | 墨消しツールを選ぶ → 文字を正確に選択 → 適用 → 保存 | **数字をクリックするだけ**（ハイフン区切りもひとかたまり） |
| 表の金額列を隠す | 範囲指定（罫線や¥記号もまとめて消える）か、1つずつ選択 | **列をざっくりドラッグ** → 中の数字だけに吸着（¥や表の罫線は残る） |
| 同じ番号が他のページにも | 自分で探す | 「同じ値がほかに3か所」→ **Enter で全部** |
| 全ページの口座番号・カード番号 | 検索して墨消し（有料機能） | **プリセットを押して Ctrl+Enter** |
| 仕上がりの確認 | 適用前は見えない | モザイク・ぼかしが**その場で本番と同じ見た目**。P長押しで原本を確認 |
| 漏れていないかの確認 | 自分で確認 | 書き出し後に**残存文字・見た目・文書情報を自動検証** |

- **数字に吸着**：ドラッグした範囲の中の数字（と数字の間の区切り）だけに、行ごとにぴったりマスクします。Alt+ドラッグで範囲そのまま。吸着は「数字 / 文字 / 自由」を `S` で切り替え（文字モードは数字以外の文字だけ、数字モードは数字だけを隠し、互いに相手を隠しません）。
- **隠し方は3種類**：モザイク・ぼかし・塗りつぶし（`1`〜`3`）。「非開示」などの文言も重ねられます。
- **モザイク・ぼかしの程度は弱・中・強**（`[` `]` で切替）：弱＝多少は推測できる程度、中＝うっすら判別できる程度、強＝ほとんど読めない。スライダーで細かくも調整できます。
- **塗りつぶしは色と透明度を選べます**：黒・チャコール・グレー・白・ネイビーなどの色見本と、任意の色。透明度を上げると下の内容があえて透けて見えます（書き出したPDFでも同じ見た目。「加工したとおり」では透けて見える部分も画像になり、元の文字データは削除されます）。
- **検索して隠す**：電話番号・金額・日付・カード番号・口座番号・マイナンバー・郵便番号・メール・すべての数字のプリセット、自由な文字列・正規表現。全角半角を区別しません。
- **スキャンしたPDF**（文字情報のない画像だけのページ）は、開くと自動で**文字認識（OCR）**し、ふつうのPDFと同じように数字への吸着・検索・プリセットが使えます。スキャンに透明の文字層が重なったPDF（複合機の「OCR付きPDF」など。重なった文字は見た目とずれていたり読み違いがあったりする）も、見た目から読み直します。表示中のページから順に処理し（4コア以上なら2ページ並行、資料によっては時間がかかります）、横向き・逆さまに貼られた資料も向きを判断して読みます。認識はブラウザの中で行い（Tesseract のWASM版と日本語モデルをアプリと一緒に配信）、外には送りません。認識の前に、色の付いたセル・灰色の網掛け・マーカー・表の罫線を消し、オレンジや赤の文字は黒くして、読みやすい画像に整えます。前処理で消えた薄い数字・白抜き数字に備え、前処理した画像で読めなかった所だけを元画像から切り出して読み直し、数字の候補を追加します（ページ全体は読み直さないので、速くなっています）。読み落としに備えて、数字は前後の隙間まで広めに隠し、書き出しのレポートでは目での確認を促します。
- **文字のあるPDFの、文字情報のない部分**：画像として貼られた表やスクリーンショット、図にした数字（グラフの数値など）、文字化けした文字（文字の対応表がないフォント）は、PDFの文字の部分を白く消してから文字認識し、PDFの文字層に足します。
- **PDFの文字の枠を字形に合わせる**：フォントの決まった高さではなく実際の字形から文字の上下の範囲を求めるので、フォントによって隠す範囲が上下にずれたり、隣の行にかかったりしません。
- **高精度の文字認識（クラウド・上級者向け）**：ふだんは不要で、APIキーを入れなければ画面にも出ません。設定（⚙）でご自身の Google Cloud の APIキーを入れた場合だけ、文書ごとに確かめてから、文字認識するページの画像を Google Cloud Vision に送って読み直せます（PDFの文字がある部分は白く消して送ります。PDFファイルそのもの・ファイル名は送りません）。キーはそのブラウザにだけ保存し、無料枠（月1,000枚）を超えないよう、1つのブラウザから月900枚で送るのを止めます。
- **テキスト枠**（マスクとは別の機能）：`T` キー（または上のツール）でページの上にドラッグして枠を作ると、そのまま中に文字を入力できます。枠を選んで `Enter`／`F2`／ダブルクリックでも入力でき、`Esc` か枠の外のクリックで終わります。**文字の大きさ**は、枠の上に出る操作バーのサイズ欄（数字を入れるか一覧から選ぶ）、`A−` `A＋`、`Ctrl+Shift+>` / `<`（`Ctrl+]` / `[`）で変えられます（PowerPoint と同じ段階）。太字・文字色・左／中央／右揃え・塗り・枠線も選べます。移動・リサイズ・削除・Undo にも対応し、書き出すとPDFのページの上に重なります（文字は画像になるので、PDFの文字としては検索・選択できません。下のページの文字は消えないので、隠すときはマスクを使います）。
- **複数ファイル**をまとめて開き、ファイルごと（ZIP）または1つに結合して書き出せます。
- ページの**回転・削除・並べ替え**。左のページ一覧は PowerPoint のスライド一覧と同じ操作です：クリックで選択、`Ctrl`（Macは`⌘`）+クリックで追加・解除、`Shift`+クリックで範囲選択、`Ctrl+A` で全選択、`Delete` で選んだページをまとめて削除（1ページだけも可）、右クリックメニュー、選んだページをまとめてドラッグして並べ替え。削除は `Ctrl+Z` で戻せます（すべてのページは削除できません。ファイルごと閉じてください）。
- **Undo/Redo**、作業の**自動保存と復元**（マスクの位置・ページ構成・テキスト枠に入れた文字だけを保存。PDF本体や隠した文字は保存しません）。

## 使い方ガイド

`public/manual/` に、実際の画面・操作動画・その場で試せるお試しエリアつきの使い方ガイドがあります（公開URLでは `/manual/`）。アプリの起動画面とヘルプからも開けます。画面写真と動画は Playwright でアプリを操作して撮影したものです。

## 書き出しの仕上がり

どれを選んでも、モザイク・ぼかしの程度や塗りは**画面で加工したとおりの見た目**で書き出されます。違いは、隠した部分の下にある元の文字データの扱いです。

| 仕上がり | 見た目 | 隠した部分の元の文字データ |
| --- | --- | --- |
| 加工したとおり（おすすめ） | 画面のまま | 削除（コピー・検索でも読めない） |
| 見た目だけ重ねる | 画面のまま | 残る（コピー・検索で読める。見た目を和らげれば十分なとき用） |
| 全ページを画像にする | 画面のまま（全体が画像） | 文字情報そのものがなくなる（最も安全） |

## 安全性の設計

「加工したとおり」では、上に絵を重ねるだけでなく、隠した部分の下の内容を**恒久的に削除**します。

1. 注釈・フォームを平坦化（注釈内の数字の取りこぼしを防ぐ）
2. 隠す範囲の**文字・画像の画素・範囲内の図形を削除**（MuPDF の墨消し）
3. 削除した場所に、元の見た目から作ったモザイク／ぼかし画像（または塗り）を配置
4. 文書情報・XMP・構造タグ、添付ファイル・JavaScript・埋め込みサムネイルを削除（選択可）
5. 増分保存を使わず**全体を書き直して保存**（古い版に元の数字が残らない）。必要ならAES-256で暗号化
6. **自動検証**：書き出したPDFを開き直して、①マスク内に文字が残っていないか ②マスク外の見た目が変わっていないか（画素比較） ③文書情報が消えているか ④隠した値と同じ文字列がマスク外に残っていないか、を確認してレポート

「全ページを画像にする」を選ぶと、文字情報を一切持たないPDFになります（最も安全・検索不可）。

マスクを選択し、上に出る丸いハンドルをドラッグすると自由に回転できます。Shiftを押すと15度刻みになり、選択ツールバーでは角度を0.1度単位で指定できます。回転マスクのあるページは書き出し時に周囲の見た目を保つ画像が追加されるため、容量が増えることがあります。また、マスクに接する文字や図形は枠外まで削除される場合があります。

本番ビルドには外部への通信を禁止するCSPを埋め込んでいるため、ブラウザ側でもファイルが外に出ないことを保証しています（例外は、設定でAPIキーを入れた場合だけ使う高精度の文字認識の送り先 `https://vision.googleapis.com`）。

## 主なショートカット

| キー | 動作 |
| --- | --- |
| ドラッグ / クリック | 範囲内の数字を隠す / 数字のかたまりを隠す |
| Alt + ドラッグ | 範囲そのままを隠す |
| `1` `2` `3` | モザイク / ぼかし / 塗りつぶし（選択中のマスクにも適用。塗りの色・透明度は上のバーで選択） |
| `S` | 吸着の切替（数字 → 文字 → 自由） |
| `[` `]` | モザイク・ぼかしの程度（弱・中・強）を切り替え |
| `Enter` | 「同じ値をすべて隠す」 |
| `P`（長押し） | 原本を確認 |
| `Ctrl+F` → `Ctrl+Enter` | 検索して一括で隠す |
| `Delete` / 矢印 | 削除 / 1pt移動（Shiftで10pt） |
| `Ctrl+Z` / `Ctrl+Shift+Z` | 元に戻す / やり直す |
| `Ctrl+S` / `Ctrl+O` | 書き出す / 開く |
| `Ctrl+L` `Ctrl+R` `Ctrl+D` | 表示中のページを左回転 / 右回転 / 削除 |
| ページ一覧で `クリック` `Ctrl+クリック` `Shift+クリック` | ページを選ぶ / 追加・解除 / 範囲選択 |
| ページ一覧で `↑` `↓` `Shift+↑↓` `Home` `End` `Ctrl+A` | 選択を動かす / 範囲を広げる / 先頭・末尾へ / すべて選択 |
| ページ一覧で `Delete` `Backspace` | 選んだページをまとめて削除（`Ctrl+Z` で戻せる） |
| `Space`（押しながら） / `Ctrl+ホイール` | パン / カーソル位置でズーム |
| `F` / `Tab` / `?` | 全画面 / パネルを隠す / ヘルプ |

## 開発

```bash
npm install
npm run dev        # 開発サーバー
npm test           # 文字の吸着・検索プリセット・書き出し（墨消し・暗号化・検証）・文字認識のテスト
npm run build      # dist/ に静的ファイルを出力（どこにでも置ける。サーバー処理は不要）
python3 scripts/make_sample.py   # 試用サンプル public/sample.pdf を作り直す（架空データ）
```

### 構成

```
src/
  engine/   MuPDF を動かす Web Worker（描画・文字抽出・書き出し・検証）
  fx/       モザイク・ぼかしの処理（画面のプレビューと書き出しで同じコード）
  model/    状態管理（Undo/Redo）、文字の吸着・検索、プリセット、自動保存、スキャンしたページの文字認識
  render/   ページ画像のキャッシュと、マスク効果の描画
  ui/       画面（ビューア、サムネイル、検索、書き出し など）
```

### バージョン

- バージョンは `package.json` の `version`。変更点は [CHANGELOG.md](CHANGELOG.md) に書く（機能追加は 1.x.0、修正は 1.x.y）。
- ビルド時に、バージョン・ビルド日時（日本時間）・元になったコミットを埋め込み、ヘルプ（`?`）・「安全性について」・起動画面・使い方ガイドの下に表示する。公開中の版は `/version.json` でも確認できる。

### デプロイ

Render の静的サイト（Static Site）として、`main` ブランチへのプッシュで自動デプロイされます。

| 項目 | 値 |
| --- | --- |
| Build Command | `npm ci && npm run build` |
| Publish Directory | `dist` |
| Branch | `main` |

サーバー側の処理はないため、`dist/` の中身はどの静的ホスティング（GitHub Pages、Vercel、社内のWebサーバーなど）にも置けます。外部通信を禁止するCSPは `index.html` に埋め込まれています。

## 機能マスタとの対応

P0（MVP）のうち、実装したもの：PDFを開く（ダイアログ・ドラッグ&ドロップ・複数）、パスワード付きPDFを開く、書き出し（元ファイルは上書きしない）、サムネイル、ドラッグでの並べ替え、回転、削除、結合、暗号化と権限7項目（AES-256既定、閲覧用と権限パスワードが同じときは権限設定を無効化）、文書プロパティ、Undo/Redo、ショートカット、オフライン動作、数字モザイク一式（範囲ドラッグで数字に吸着、数字のかたまり選択、即時プレビュー、ピクセル化・ぼかしでの墨消し、恒久削除、検索して墨消し、サニタイズ、漏えい検証、全体を書き直す保存）。P1の自動保存・復元、注釈の平坦化、ページのラスタライズも含みます。

未実装（必要になったら追加）：任意位置へのPDF・画像の挿入、ページ抽出・1ページずつ保存、結合時のしおり維持、最近使ったファイル。

## ライセンス

PDFエンジンに [MuPDF.js](https://mupdf.readthedocs.io/)（AGPL-3.0）を使っているため、このアプリを配布・公開する場合は AGPL-3.0 に従う必要があります（社外向けに提供する場合はソースコードの公開が必要）。文字認識には [Tesseract.js](https://github.com/naptha/tesseract.js) と Tesseract の日本語モデル（いずれも Apache-2.0）を使っています。

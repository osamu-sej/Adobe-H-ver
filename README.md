# カクス — PDFモザイク・墨消しツール

PDFの「見せられない部分」（電話番号・金額・口座・マイナンバーなど）を、**クリックとドラッグだけで**隠して、**文字ごと完全に削除したPDF**として書き出すブラウザアプリです。
PDFの処理はすべてブラウザ内のPDFエンジン（MuPDF / WebAssembly）で行い、**ファイルは端末の外に一切送信しません**。

## 速く隠すための工夫

| 操作 | Adobe Acrobat での一般的な手順 | カクス |
| --- | --- | --- |
| 電話番号を1つ隠す | 墨消しツールを選ぶ → 文字を正確に選択 → 適用 → 保存 | **数字をクリックするだけ**（ハイフン区切りもひとかたまり） |
| 表の金額列を隠す | 範囲指定（罫線や¥記号もまとめて消える）か、1つずつ選択 | **列をざっくりドラッグ** → 中の数字だけに吸着（¥や表の罫線は残る） |
| 同じ番号が他のページにも | 自分で探す | 「同じ値がほかに3か所」→ **Enter で全部** |
| 全ページの口座番号・カード番号 | 検索して墨消し（有料機能） | **プリセットを押して Ctrl+Enter** |
| 仕上がりの確認 | 適用前は見えない | モザイク・ぼかしが**その場で本番と同じ見た目**。P長押しで原本を確認 |
| 漏れていないかの確認 | 自分で確認 | 書き出し後に**残存文字・見た目・文書情報を自動検証** |

- **数字に吸着**：ドラッグした範囲の中の数字（と数字の間の区切り）だけに、行ごとにぴったりマスクします。Alt+ドラッグで範囲そのまま。吸着は「数字 / 文字 / 自由」を `S` で切り替え（文字モードは数字以外の文字だけ、数字モードは数字だけを隠し、互いに相手を隠しません）。
- **隠し方は3種類**：モザイク・ぼかし・塗りつぶし（`1`〜`3`）。「非開示」などの文言も重ねられます。
- **モザイク・ぼかしの程度は弱・中・強**（`[` `]` で切替）：弱＝多少は推測できる程度、中＝うっすら判別できる程度、強＝ほとんど読めない。スライダーで細かくも調整できます。
- **塗りつぶしは色と透明度を選べます**：黒・チャコール・グレー・白・ネイビーなどの色見本と、任意の色。透明度を上げると下の内容があえて透けて見えます（書き出したPDFでも同じ見た目。「加工したとおり」では透けて見える部分も画像になり、元の文字データは削除されます）。
- **検索して隠す**：電話番号・金額・日付・カード番号・口座番号・マイナンバー・郵便番号・メール・すべての数字のプリセット、自由な文字列・正規表現。全角半角を区別しません。
- **画像だけのページ**（スキャン）は、ドラッグした範囲をそのまま隠します。
- **複数ファイル**をまとめて開き、ファイルごと（ZIP）または1つに結合して書き出せます。
- ページの**回転・削除・並べ替え**（サムネイルをドラッグ）、**Undo/Redo**、作業の**自動保存と復元**（マスクの位置だけを保存。PDF本体や隠した文字は保存しません）。

## 書き出しの仕上がり

どれを選んでも、モザイク・ぼかしの程度や塗りは**画面で加工したとおりの見た目**で書き出されます。違いは、隠した部分の下にある元の文字データの扱いです。

| 仕上がり | 見た目 | 隠した部分の元の文字データ |
| --- | --- | --- |
| 加工したとおり（おすすめ） | 画面のまま | 削除（コピー・検索でも読めない） |
| 見た目だけ重ねる | 画面のまま | 残る（コピー・検索で読める。見た目を和らげれば十分なとき用） |
| 全ページを画像にする | 画面のまま（全体が画像） | 文字情報そのものがなくなる（最も安全） |

## 安全性の設計

「加工したとおり」では、上に絵を重ねるだけでなく、隠した部分の下の内容を**恒久的に削除**します。

1. 注釈・フォームを平坦化（注釈内の数字の取りこぼしを防ぐ）
2. 隠す範囲の**文字・画像の画素・範囲内の図形を削除**（MuPDF の墨消し）
3. 削除した場所に、元の見た目から作ったモザイク／ぼかし画像（または塗り）を配置
4. 文書情報・XMP・構造タグ、添付ファイル・JavaScript・埋め込みサムネイルを削除（選択可）
5. 増分保存を使わず**全体を書き直して保存**（古い版に元の数字が残らない）。必要ならAES-256で暗号化
6. **自動検証**：書き出したPDFを開き直して、①マスク内に文字が残っていないか ②マスク外の見た目が変わっていないか（画素比較） ③文書情報が消えているか ④隠した値と同じ文字列がマスク外に残っていないか、を確認してレポート

「全ページを画像にする」を選ぶと、文字情報を一切持たないPDFになります（最も安全・検索不可）。

本番ビルドには外部への通信を禁止するCSPを埋め込んでいるため、ブラウザ側でもファイルが外に出ないことを保証しています。

## 主なショートカット

| キー | 動作 |
| --- | --- |
| ドラッグ / クリック | 範囲内の数字を隠す / 数字のかたまりを隠す |
| Alt + ドラッグ | 範囲そのままを隠す |
| `1` `2` `3` | モザイク / ぼかし / 塗りつぶし（選択中のマスクにも適用。塗りの色・透明度は上のバーで選択） |
| `S` | 吸着の切替（数字 → 文字 → 自由） |
| `[` `]` | モザイク・ぼかしの程度（弱・中・強）を切り替え |
| `Enter` | 「同じ値をすべて隠す」 |
| `P`（長押し） | 原本を確認 |
| `Ctrl+F` → `Ctrl+Enter` | 検索して一括で隠す |
| `Delete` / 矢印 | 削除 / 1pt移動（Shiftで10pt） |
| `Ctrl+Z` / `Ctrl+Shift+Z` | 元に戻す / やり直す |
| `Ctrl+S` / `Ctrl+O` | 書き出す / 開く |
| `Ctrl+L` `Ctrl+R` `Ctrl+D` | 表示中のページを左回転 / 右回転 / 削除 |
| `Space`（押しながら） / `Ctrl+ホイール` | パン / カーソル位置でズーム |
| `F` / `Tab` / `?` | 全画面 / パネルを隠す / ヘルプ |

## 開発

```bash
npm install
npm run dev        # 開発サーバー
npm test           # 文字の吸着・検索プリセット・書き出し（墨消し・暗号化・検証）のテスト
npm run build      # dist/ に静的ファイルを出力（どこにでも置ける。サーバー処理は不要）
python3 scripts/make_sample.py   # 試用サンプル public/sample.pdf を作り直す（架空データ）
```

### 構成

```
src/
  engine/   MuPDF を動かす Web Worker（描画・文字抽出・書き出し・検証）
  fx/       モザイク・ぼかしの処理（画面のプレビューと書き出しで同じコード）
  model/    状態管理（Undo/Redo）、文字の吸着・検索、プリセット、自動保存
  render/   ページ画像のキャッシュと、マスク効果の描画
  ui/       画面（ビューア、サムネイル、検索、書き出し など）
```

### デプロイ

Render の静的サイト（Static Site）として、`main` ブランチへのプッシュで自動デプロイされます。

| 項目 | 値 |
| --- | --- |
| Build Command | `npm ci && npm run build` |
| Publish Directory | `dist` |
| Branch | `main` |

サーバー側の処理はないため、`dist/` の中身はどの静的ホスティング（GitHub Pages、Vercel、社内のWebサーバーなど）にも置けます。外部通信を禁止するCSPは `index.html` に埋め込まれています。

## 機能マスタとの対応

P0（MVP）のうち、実装したもの：PDFを開く（ダイアログ・ドラッグ&ドロップ・複数）、パスワード付きPDFを開く、書き出し（元ファイルは上書きしない）、サムネイル、ドラッグでの並べ替え、回転、削除、結合、暗号化と権限7項目（AES-256既定、閲覧用と権限パスワードが同じときは権限設定を無効化）、文書プロパティ、Undo/Redo、ショートカット、オフライン動作、数字モザイク一式（範囲ドラッグで数字に吸着、数字のかたまり選択、即時プレビュー、ピクセル化・ぼかしでの墨消し、恒久削除、検索して墨消し、サニタイズ、漏えい検証、全体を書き直す保存）。P1の自動保存・復元、注釈の平坦化、ページのラスタライズも含みます。

未実装（必要になったら追加）：任意位置へのPDF・画像の挿入、ページ抽出・1ページずつ保存、結合時のしおり維持、最近使ったファイル、OCR（スキャンPDFの数字への吸着）。
